# Checkout Test Fill — Chrome Web Store listing copy

Use the text below in the Store listing tab. Keep the extension name as **Checkout Test Fill** for this package; the ZIP's manifest uses that name. The screenshots and privacy practices are separate dashboard fields.

## English listing

**Primary category:** Developer Tools

**Short description (already in the extension manifest):**

Fill US test contact details, addresses, and optional test card fields on checkout pages.

**Detailed description:**

Checkout Test Fill helps ecommerce developers and authorized testers fill checkout forms with realistic-looking sample data instead of placeholders such as 111, 222, or abc. On first use, read the short notice at the middle right of a checkout page and click Enable and generate. Then use Generate on checkout pages to create a new set of US contact and shipping details whenever you need one.

The extension supports common single-page and multi-step checkouts. It generates test names, email addresses in Gmail or Outlook format, US phone numbers, and California addresses. Choose the interface language and the country and state settings in the extension popup. A built-in address dataset is currently available for California; when you choose another state, enter its street address, city, and ZIP code yourself.

Optional test-card filling is available for recognized card fields. The three built-in cards are Stripe test cards, including one marked 3DS. You can add and reorder test cards for other payment providers. Use each card only in the corresponding provider's test environment. Some embedded payment fields may not be accessible to the extension.

The extension fills fields locally in your browser. It does not submit orders or payments. Generated email addresses may not receive messages. Use it only on checkout pages you are authorized to test, and do not save real payment card details in its settings.

## 简体中文商店详情

**类别：**开发者工具

**简短说明（已写入插件）：**

在 checkout 页面填写美国测试联系资料、地址和可选的测试卡字段。

**详细说明：**

Checkout Test Fill 帮助电商开发者和获准测试人员使用看起来合理的测试资料填写 checkout 表单，减少 111、222、abc 等占位内容对测试的干扰。首次使用时，在结账网页右侧中间阅读简短的数据说明并点击“启用并生成”；之后可在相同位置点击“生成资料”换一组美国测试联系资料和收货信息。

插件支持常见的单页和多步骤结账表单，可生成测试姓名、Gmail 或 Outlook 格式的邮箱地址、美国电话号码和加州地址。你可以在插件弹窗中设置界面语言、国家和州。目前仅内置加州地址数据；选择其他州时，街道、城市和邮编需自行填写。

对于识别到的信用卡字段，可选择自动填写测试卡。内置三张 Stripe 测试卡，其中一张标注 3DS；你也可以添加其他支付服务商的官方测试卡并调整顺序。测试卡仅应在对应支付服务商的测试环境中使用。部分内嵌支付字段可能无法由插件访问。

插件在浏览器本地填写表单，不会自动提交订单或付款。生成的邮箱地址不保证可收信。请仅在获准测试的 checkout 页面使用，也不要在插件设置中保存真实银行卡资料。
